# 🧠 LeetCode Challenges

Bem-vindo(a), aqui é onde eu choro e minha mãe não vê (e evoluo também) resolvendo problemas do [LeetCode](https://leetcode.com/)! 🚀

A ideia aqui é simples: sempre que eu encarar um desafio novo, ele vem parar neste repositório. Nada de resolver e esquecer — aqui fica registrado o código, a lógica por trás dele e, principalmente, o meu progresso ao longo do tempo.

Se você caiu aqui de paraquedas: seja bem-vindo(a) à uma parte do meu mundo onde eu treino lógica, estrutura de dados e paciência (muita paciência). 😅

## 📁 Como o repositório está organizado

Os desafios são separados por nível de dificuldade, exatamente como o próprio LeetCode classifica:

```
LeetCode-Challenges/
├── easy/
├── medium/
└── hard/
```

Dentro de cada uma dessas pastas, cada exercício resolvido ganha a sua própria pastinha, contendo:

- 📄 **`solution.py`** → o código da solução em Python
- 📝 **`README.md`** → a descrição do problema, explicando do que se trata o desafio

Ou seja, a estrutura fica mais ou menos assim:

```
easy/
└── nome-do-desafio/
    ├── solution.py
    └── README.md

medium/
└── outro-desafio/
    ├── solution.py
    └── README.md

hard/
└── desafio-racha-cranio/
    ├── solution.py
    └── README.md
```

Simples, direto e fácil de navegar — dá pra abrir qualquer pasta e já entender do que se trata o problema e como ele foi resolvido.

## 🎯 Pra que serve esse repositório?

Basicamente três motivos:

1. **Praticar de verdade** — resolver problema é bem diferente de só ler sobre algoritmos.
2. **Criar um histórico** — daqui a um tempo olhar pra trás e ver a evolução (e rir de umas soluções toscas do passado, com certeza vai ter).
3. **Servir de referência** — tanto pra mim revisar algo que já resolvi, quanto pra quem estiver estudando e passar por aqui.

## 🐍 Tecnologia usada

Atualmente todas as soluções são escritas em **Python**, por ser a linguagem que tenho mais me aprofundado.

Se eu endoidar, talvez futuramente aqui também tenha resoluções em java.

## 📌 Sobre o conteúdo

Cada desafio é resolvido com calma, tentando sempre pensar na solução mais clara possível antes de partir pra otimizações. Afinal, o objetivo aqui não é só "passar no LeetCode", e sim realmente entender o problema e a lógica usada pra resolvê-lo.
